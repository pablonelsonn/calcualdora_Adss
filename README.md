# 🧮 Calculadora em C

## 📌 Sobre o projeto

Este projeto consiste em uma calculadora básica desenvolvida na linguagem C como atividade acadêmica da faculdade.

O objetivo foi aplicar os conceitos iniciais de programação, compreendendo como receber valores do usuário, realizar operações matemáticas e apresentar os resultados na tela.

## 🎯 Objetivos

* Praticar lógica de programação.
* Desenvolver algoritmos simples.
* Trabalhar com variáveis e operadores matemáticos.
* Utilizar estruturas condicionais.
* Aplicar os conhecimentos adquiridos durante a faculdade.

## ⚙️ Tecnologias e ferramentas utilizadas

* **Linguagem:** C
* **Editor de código:** Visual Studio Code
* **Compilador:** GCC ou outro compilador C compatível, conforme a configuração do ambiente.

## ➕ Funcionalidades

A proposta do projeto é realizar operações matemáticas básicas, como:

* Adição.
* Subtração.
* Multiplicação.
* Divisão.

*As operações acima representam a proposta de uma calculadora básica; mantenha na descrição final somente as funcionalidades implementadas no seu código.*

## ▶️ Como executar

Para executar o projeto, é necessário ter um compilador C instalado e configurado.

1. Abra o projeto no Visual Studio Code.
2. Abra o terminal na pasta do arquivo.
3. Compile o programa com o GCC, caso esteja instalado:

```bash
gcc calculadora.c -o calculadora
```

4. Execute o programa no terminal.

No Windows:

```bash
.\calculadora.exe
```

*Observação: substitua `calculadora.c` pelo nome real do arquivo, caso seja diferente.*
